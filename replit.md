# Motoluxe UI Showcase

## Run locally in Replit

This is a frontend-only React + TypeScript application using TanStack Start and Vite.

```sh
bun install --frozen-lockfile
bun run dev
```

The Replit workflow is configured as **Start application** and serves the app on port `5000`.

## Project scope

The imported project is a static UI showcase for Motoluxe autocare and bike-care products. It does not require a backend, authentication, payments, or external service credentials.
